# Dayflow - Human Resource Management System

> Every workday, perfectly aligned.

## 🚀 Overview
Dayflow is an HRMS platform built to streamline employee onboarding, role-based dashboards, attendance logging, leave approvals, and payroll visibility.

## 👥 User Roles
- **Admin / HR Officer:** Employee management, attendance/leave approvals, payroll configuration.
- **Employee:** Profile management, check-in/out, leave application, view salary details.

## 🛠️ Core Modules
- **Auth & RBAC:** JWT/session authentication with Admin and Employee roles.
- **Attendance:** Check-in/check-out system with daily and weekly views.
- **Leave Management:** Application workflow (Paid, Sick, Unpaid) with Admin approval/rejection.
- **Payroll:** Secure salary structure viewing and administrative controls.

## 💻 Tech Stack
- **Frontend:** [e.g., React / Next.js / Vue]
- **Backend:** [e.g., Node.js Express / FastAPI / Spring Boot]
- **Database:** [e.g., PostgreSQL / MongoDB]

## ⚙️ Getting Started
1. Clone the repo: `git clone <repo-url>`
2. Setup Backend: `cd backend && npm install && npm run dev`
3. Setup Frontend: `cd frontend && npm install && npm run dev`
