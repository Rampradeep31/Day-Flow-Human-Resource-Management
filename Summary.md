# Dayflow — Human Resource Management System

> Every workday, perfectly aligned.

Dayflow is an HRMS that digitizes core HR operations — onboarding, attendance, leave, and payroll visibility — with role-based workflows for Employees and Admin/HR Officers.

## 🚀 Features

### 🔐 Authentication & Authorization
- Sign up with Employee ID, Email, Password, Role (Employee/HR)
- Email verification & password security rules
- Secure sign-in with error handling on invalid credentials

### 📊 Dashboards
- **Employee:** quick-access cards for Profile, Attendance, Leave Requests, recent activity
- **Admin/HR:** employee list, attendance records, leave approvals, switch-between-employee view

### 👤 Employee Profile Management
- View: personal details, job details, salary structure, documents, profile picture
- Edit: employees can update limited fields (address, phone, photo); admins can edit all fields

### 🕒 Attendance Management
- Daily/weekly attendance views
- Check-in / check-out
- Status types: Present, Absent, Half-day, Leave
- Employees see only their own records; Admin/HR sees all

### 🏖️ Leave & Time-Off Management
- Apply for Paid / Sick / Unpaid leave with date range & remarks
- Status tracking: Pending → Approved / Rejected
- Admin can approve/reject with comments; updates reflect instantly

### 💰 Payroll Management
- Employees: read-only payroll view
- Admin: view all payrolls, update salary structures, ensure accuracy

### 📈 Extras
- Email & notification alerts
- Analytics & reports dashboard (salary slips, attendance reports)

## 👥 User Roles

| Role | Access |
|------|--------|
| **Admin / HR Officer** | Manage employees, approve leave & attendance, view payroll |
| **Employee** | View profile, attendance, apply for leave, view salary |
