# Dayflow HRMS — Unified Frontend Portal

Unified React 19 + Vite frontend application for **Dayflow Human Resource Management System**.

## Features
- **Unified Role Navigation**: Seamlessly integrates **HR Admin Console** and **Employee Self-Service Portal** with automatic role-based access control (RBAC).
- **Core Modules**:
  - **Dashboard**: Role-tailored metrics, live workday check-in timer, quick action hubs, and upcoming schedule.
  - **Attendance & Workday Logs**: Daily punch timeline, weekly schedule grid, monthly calendar, and company-wide attendance management for HR.
  - **Leave & Time-Off**: Leave balance tracking, instant leave application, and HR approval queue with real-time approvals.
  - **Payroll & Salary**: Monthly salary breakdowns, interactive gross-to-net calculators, salary revision tools, and printable payslips.
  - **Employee Directory & Profiles**: Complete personnel directory with department filtering, search, and profile editing.
  - **Analytics & Reporting**: Company health KPIs, headcount distribution charts, leave utilization trends, and CSV/PDF data exports.
  - **Pluggable AI Chatbot (DayBot)**: Floating assistant for instant HR policy queries, leave checks, and HRMS navigation.
- **Modern UI & Aesthetic Excellence**:
  - Glassmorphism surfaces, sleek dark/light theme switching, custom gradients.
  - Micro-animations, subtle sound cues, confetti celebrations, and command palette (`Ctrl+K` / `Cmd+K`).

## Quick Start
```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
